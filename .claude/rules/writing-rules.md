## When writing documents & comments

- Every line changes what the reader does. Delete the ones that don't.
- Keep each meaning in one authoritative place; reference the others by path or URL (specs, plans, ADRs, issues, commits, diffs).
- Write the sentence you would otherwise have to re-derive, not the transcript.
- Apply progressive disclosure: keep the main file to what every reader needs, and put the rest behind a pointer to it.
